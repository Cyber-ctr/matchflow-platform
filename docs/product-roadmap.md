# MatchFlow Product Roadmap

## Release 1 — Marketplace foundation

- Talent profiles
- Employer profiles
- Opportunities
- Applications
- Search/filter
- Skills-based matching
- Messaging
- Notifications
- Apprenticeships
- Assessments
- Reviews
- Admin moderation

## Release 2 — Monetisation

- Paid employer plans
- Featured opportunities
- Placement fees
- Employer invoices
- Payment webhooks
- Promotion analytics

## Release 3 — Institutional ecosystem

- TVET/university organisation accounts
- Cohort management
- Training and assessment partnerships
- Institution dashboards
- Apprenticeship reporting

## Release 4 — Mobile and intelligence

- Android app
- Push notifications
- Better matching model using observed outcomes
- Recommendation quality metrics
- Fraud/risk signals
- iOS client after mobile demand is proven
